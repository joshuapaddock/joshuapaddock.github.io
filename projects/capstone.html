Adaptive routing for LLM inference clusters

Formulating single-rack LLM request routing as an optimal control problem: a KV-cache-aware policy that maps prefill and decode queues and replica capacity to request placements, under time-to-first-token (TTFT) and throughput targets.

Status
In progress

Supervisors

Problem

Decide where each inference request runs so latency and throughput targets hold as load shifts.

Approach

Model routing as a stochastic control problem (a Markov decision process) and derive a policy from it.

Status

In progress

Results will be posted as the project develops.

01 Problem

Common load-balancing rules like least-loaded routing look at a single signal. Inference servers carry much more state: queued prefill and decode work, KV-cache occupancy, and replica capacity. Routing that ignores it can miss latency targets under bursty traffic.

02 Formulation

  • State: prefill and decode queue lengths, KV-cache usage and capacity per replica.
  • Action: which replica receives the next request.
  • Cost: violations of TTFT and throughput targets.
